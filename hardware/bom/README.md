# Bill of materials

[`bom.csv`](bom.csv) lists every part with its reference (matching the [schematic](../schematic)), quantity, key specs and a search term that finds it on AliExpress and similar stores.

The **Unit price** and **Link** columns are left blank on purpose: prices change, so fill them in with what you actually paid.

Parts for the enclosure (screws, inserts, filament) will be added together with the [enclosure](../enclosure) model.
